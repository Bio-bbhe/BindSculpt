# BindSculpt

BindSculpt is a tool for **protein-ligand binding region design**, leveraging sequence generation models (e.g., seq2seq). This project offers various sampling strategies and structural template assistance to help researchers explore and design novel binding interfaces.

-----

## Quick Start

First, ensure you have installed all necessary dependencies. You can find them listed in `requirements.txt`:

```bash
pip install -r requirements.txt
```

Once dependencies are installed, run the main program:

```bash
python run_experiments.py
```

-----

## Input File Preparation

Input files **must be prepared manually** and placed within the `data/inputs/` directory. For example, if your target is `3bik_PD-1_truncated`, your `inputs/` directory should look like this:

```
inputs/
├── 3bik_PD-1_truncated.a3m         # MSA file (generated using HHblits)
├── 3bik_PD-1_truncated.fasta       # FASTA file
└── 3bik_PD1_converted.cif          # AlphaFold3 template structure (converted using script)
```

-----

## How to Prepare Input Files

Here's a step-by-step guide to preparing each required input file:

### 1\. Prepare `.fasta` file

You can obtain your target protein sequence from resources like UniProt or PDB. Save the sequence in `.fasta` format.

### 2\. Prepare `.a3m` file (Multiple Sequence Alignment)

Use the **HHblits** tool to generate your MSA file:

1.  Input your `.fasta` file into HHblits.

2.  Wait for the computation to complete.

3.  Download the `.a3m` formatted MSA file.

4.  Save it as `<target_name>.a3m`.

    *A helpful tip:* You can often find a direct download link for the `.pdb` file from the HHblits job submission page (e.g., `https://toolkit.tuebingen.mpg.de/jobs/2722865`).

### 3\. Prepare AlphaFold3 `.cif` Template Structure

If you have a PDB structure (e.g., from AlphaFold DB or generated by AF2/AF3), convert it to the required `.cif` format using our script:

```bash
python scripts/prepare_template.py <input_pdb_file> <output_cif_file>
```

**Example:**

```bash
python scripts/prepare_template.py data/inputs/3bik_PD1.pdb data/inputs/3bik_PD1_converted.cif
```

## Configuration (config.yaml)

The `config.yaml` file controls BindSculpt's behavior. You'll need to modify it to match your setup and preferences.

### Input Path Settings

**You must modify these fields** to point to your prepared input files:

```yaml
paths:
  target_fasta: data/inputs/3bik_PD-1_truncated.fasta
  data_inputs: data/inputs
  target_msa_dir: data/inputs/3bik_PD-1_truncated.a3m
  target_cif_path: data/inputs/3bik_PD1_converted.cif
```

### Optional: Disable Binding Region Constraint

If you **do not need to fix a specific binding region**, you can disable this constraint in `config.yaml`:

```yaml
define_binding:
  enabled: False
```

Alternatively, if you wish to **manually define the binding region**, enable it and specify the residues using their 1-based target sequence indices:

```yaml
define_binding:
  enabled: True
  binding_region: 1-11,68-84,148-170,241-253
```

-----

## Output

The results of your BindSculpt run will be saved in the directory specified in your configuration. By default, this is:

```yaml
base_output_dir: data/outputs_<your_run_name>
```
